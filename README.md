# Simple Calculator

A beginner-friendly calculator built with HTML, CSS and JavaScript.

## Project files
- `index.html` — calculator structure
- `style.css` — design and layout
- `script.js` — calculator operations and keyboard support

## Features
- Addition, subtraction, multiplication and division
- Clear (AC) and delete (DEL) buttons
- Decimal numbers
- Keyboard support

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html` in your browser, or install the Live Server extension.
3. Right-click `index.html` and select **Open with Live Server**.
